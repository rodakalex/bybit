# Trading Indicator Plotter

Скрипт предназначен для получения исторических данных свечей с биржи Bybit и построения графиков популярных технических индикаторов, таких как RSI, Stochastic, CCI, ADX и AO. Пользователь может настроить временной интервал, символ и тип индикатора.

---

## Возможности

- Получение исторических данных свечей через API Bybit.
- Поддержка различных временных интервалов и периодов.
- Построение популярных технических индикаторов.
- Простота настройки для добавления новых функций.

---

## Использование

Запустите скрипт с использованием следующих параметров:

```bash
python script.py <indicator> [--symbol SYMBOL] [--timeframe TIMEFRAME]
```

### Аргументы:

- `indicator` (обязательный): Тип технического индикатора для построения. Доступные варианты:
  - `rsi`
  - `stochastic`
  - `cci`
  - `adx`
  - `ao`

- `--symbol` (опционально): Торговая пара. По умолчанию: `BTCUSD`.

- `--timeframe` (опционально): Временной интервал. По умолчанию: `1m`.

### Доступные временные интервалы:

| Ключ   | Интервал | Период            |
|--------|----------|-------------------|
| `1m`   | 1 мин    | 1 день            |
| `5m`   | 5 мин    | 5 дней            |
| `15m`  | 15 мин   | 15 дней           |
| `30m`  | 30 мин   | 1 месяц           |
| `1h`   | 1 час    | 3 месяца          |
| `2h`   | 2 часа   | 6 месяцев         |
| `4h`   | 4 часа   | 6 месяцев         |
| `1d`   | 1 день   | 1 год             |
| `1w`   | 1 неделя | 2 года            |
| `1mo`  | 1 месяц  | 5 лет             |

---

### Примеры использования:

1. Построить RSI для `BTCUSD` с минутным интервалом:
   ```bash
   python script.py rsi --symbol BTCUSD --timeframe 1m
   ```

2. Построить Stochastic для `ETHUSD` с 15-минутным интервалом:
   ```bash
   python script.py stochastic --symbol ETHUSD --timeframe 15m
   ```

3. Построить CCI для `BTCUSD` с дневным интервалом:
   ```bash
   python script.py cci --symbol BTCUSD --timeframe 1d
   ```

## Описание файлов

### `BybitKlineFetcher`
Класс-утилита для получения и предобработки данных свечей через API Bybit.

### `Plotter`
Класс для построения графиков свечей с выбранным техническим индикатором.

---

## Настройка

Для добавления новых индикаторов:
1. Обновите класс `Plotter`, добавив логику нового индикатора.
2. Добавьте новый индикатор в список `choices` в настройках `argparse`.

---

## Известные ограничения

- При запросе больших объемов данных может возникнуть ограничение API Bybit.
- Для больших временных периодов время обработки может быть увеличено.
